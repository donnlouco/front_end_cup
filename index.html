REQUISITOS NECESSARIOS

Prepare o seu ambiente com as ferramentas abaixo para garantir uma participação sem interrupções.

Laboratório de Informatica

  • Ambiente de trabalho da sua equipe, equipado com computadores e acesso à internet

Visual Studio Code

  • Ferramenta principal de desenvolvimento. Necessário tê-lo instalado na máquina que será utilizada.

Conta VSCode ou GitHub

  • Crie ou vincule sua conta para gerenciar o repositório do projeto e entregar o código final.
